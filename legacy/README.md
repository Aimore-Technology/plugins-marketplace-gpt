# Historical execution package

eightdegrees-sales-workflow-0.1.58 is the unchanged original package, archived when 0.2.0 switched the installed plugin to an Activepieces client. It is not listed in the marketplace and is excluded from release ZIPs. Legacy unit tests continue to exercise its original deterministic helpers; they are regression evidence for the archive, not proof of current backend parity. Active client tests live in tests/test_activepieces_client.py.
