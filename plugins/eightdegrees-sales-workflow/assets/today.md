## Start here

Open the action-page link in a matching task row to fill information or review
the current version. The row title opens its original task details.

The lists below read the existing task database. They include older unresolved
work. An empty list means no matching saved tasks, not that the mailbox was just
scanned or that every channel has been checked.

## After you submit

Notion saves edits automatically. Checking the named submission to-do requests
processing; it does not mean accepted, executed or sent. Each action page shows
whether to wait for a verified native task or run a specific continuation.
An unconfigured/stopped schedule does not process submissions in the background.
