# Outcomes

API acceptance completes a write or dispatch; delivery is not required. Keep
Gmail/AndroidSync raw acknowledgement status and original request ID. Update
only affected task/action/source and due pointers once at the boundary. Use
email.complete for the short path and write.confirm for Notion/CRM receipts.

A future human review, future due SMS and true processing fault are different
states. Do not run an unchanged wait. Missing CRM/follow-up records repair their
own effect; they never cause another email. Accepted/pending/unknown attempts
reserve their stable identity. Replies/stops apply only to their actual source,
customer/channel/context. Preserve history; one customer's fault is not global.
