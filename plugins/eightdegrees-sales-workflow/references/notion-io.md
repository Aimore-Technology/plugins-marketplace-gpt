# Notion I/O

Use registered page/database IDs and retained complete schemas. Rediscover only
on explicit init/configuration/schema change or an actual provider error. Read
only affected active sources/tasks/actions; do not sweep historical trees.
Actual incoming operator input is read once on its original active page and
bound to the canonical task before effects. Cached AI output is not human input.

Prepare exact targeted mutations, preserving children/inputs and account scope.
An error is not an empty page. Confirm successful writes from API responses and
record IDs; no routine content readback. On unknown result resolve original
existence before retry. Coalesce required source/task/action result changes at
the business boundary and logs at cycle close. See [API policy](api-result-policy.md).
