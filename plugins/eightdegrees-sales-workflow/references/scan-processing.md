# Process only ready events

After enabled-scope discovery, use [email-flow](email-flow.md) for each new
inquiry and combined review submission. Reuse the discovered original captures;
no restart of the scanner, repeated message/CRM/file read or per-owner saved plan.
Apply stops first. Resolve project materials through [cache](project-cache.md).
Unknown project opens one input page; ordinary name resolution needs no review.

Use the full saved ready queue, including original unfinished handoffs and due
work even with no new mail. One item's block never stalls unrelated work. Keep
budget/deadline, all remaining pointers and actual wait/block reasons. A submitted
combined Approve may send under the current public/native policy; explicit no-send,
report, init and reply-draft restrictions remain. Notifications use standing SMS
authority, current channel/stop/window/count/attempt checks and no human review.

Save source/task/action results once at the phase boundary using original API
responses. Save compact duration/event/backlog/step metrics at cycle close;
update Health only from actual observations. No dashboard/history/result sweep
or delivery polling. Unknown provider actions never replay on recovery.
