# Frozen HTML preview

Use the existing render_preview.cjs with the exact local HTML package once.
Record source version, dimensions and render completion before uploading the
PNG. Keep scripts disabled and external resource failures explicit. A native
HTML preview may be used when supported; otherwise use the generated same-file
native PNG plus the original HTML link. Do not assume a fake hosted URL.

Confirm upload and preview-page publication through their original API responses.
Do not fetch reference maps, download the saved image or compare provider bytes.
The operator's single combined review shows this preview, exact copy, recipients
and window. A missing usable preview remains one scoped issue; a corrected new
version has blank choices. See [HTML approval](html-approval.md).
