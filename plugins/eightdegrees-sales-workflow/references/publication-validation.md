# Validate the proposed publication once

Check intended links, source/recipient/version, current task binding and complete
local copy/preview before submission. notion.mutation checks proposed arguments;
API response/record ID confirms the write. Do not query the saved body to compare
text, hashes or status fields. Unknown writes reconcile original existence.

Use one current status, input and result section. Preserve child pages, approved
history and operator answers. Completed controls become inactive; do not leave
old waiting prompts active. Repair only the affected projection; never repeat
an external provider or CRM action for presentation. See [email-flow](email-flow.md).
