# 0.1.14 Portable Experience library

The user requested Experience at the plugin root, distributed with the plugin and read by Skills. Add an English operation-to-card index and five concise cards for connector contracts, Notion edits, workflow integrity, mail delivery and testing/evidence. The command entry and shared operating contract require selective consultation before the affected operation, with invocation-local reuse instead of loading the whole library. Reply and SMS owners link directly to their relevant transport/connector cards.

Lessons are based on the 0.1.13 directed report and earlier recurrence. Each records trigger/scope, actual observation, recommended action, verification and open limitations. Portable cards contain no customer destinations, message samples, credentials or live workspace IDs, and require no development Notion access. The detailed eleven-family classification and source link are in review-0.1.13.md.

This is a knowledge/instruction release. It does not fix the open communication DataCompletion route, establish byte-exact Gmail reply transport, add SMS inbound access or enforce an independent execution engine. It grants no send permission and performs no live retest. Existing approvals, unknown attempts, stop/Pause and command restrictions remain unchanged. Actual tool contracts take precedence over version-scoped historical observations.

Validation uses the existing offline regression suite, Skill/reference/package checks and shared-payload parity. Live confirmation that a model consistently applies a tip remains a separate workflow acceptance result; the existence of the card is not a passing test.
