# EightDegrees Sales Workflow 0.1.55

Normal local check output is now a self-contained private phase artifact with
original inputs, plan and results in one atomic file. No preliminary or separate
preserve-original-records call is needed. Next phases load that artifact directly
with --captures and merge only newly returned objects. An immutable alias cannot
silently change. Identical artifacts do not rewrite; original refusal evidence
survives failed checks without promoting captured proposed calls to authority.

Native v4 consent discovery reuses the existing complete task-list query/view
projection. scan.watches returns row input records and only changed/demanded
canonical task URLs. Unchanged consent/text without executable recovery needs
no full task fetch. Missing fields fall back to the original page; incomplete
coverage refuses an idle claim. Actual full current tasks still bind approval
and imminent dispatch. Legacy body forms remain observable and are not cached
away. Saved recovery continues even without row edits. No new service or timer.

This targets repeated local save calls and indiscriminate Notion fetches; it
cannot hide native connector calls or prove the screenshot's exact call counts
without access to that Work task's underlying execution log. Host orchestration,
Notion query capability and actual live latency still need measurement. The
email-anytime rule and independent SMS timing are unchanged.

Offline regressions cover a single saved artifact with originals/results,
artifact-to-next-phase reuse, zero-write identical output, atomic refusal,
original diagnostic retention, 100 unchanged rows with zero detail fetches,
two changed consents with two detail pointers, withdrawal/text changes,
incomplete projection fallback and unchanged ready recovery demand.
