# EightDegrees Sales Workflow 0.1.51

New inquiry replies are actual text/plain messages. One short review page shows
recipients, subject, readable text, send window, decision and revision comments.
No HTML, JSON, base64, hashes, browser rendering, screenshot, preview upload,
separate copy or full inline brochure is needed. An existing usable brochure
link can be included when appropriate; never invent public access.

Technical draft/source/version binding moves to the original canonical task.
The registered human action page supplies only the real human decision. Editing
text, recipients or window invalidates the old package. Exact-version approval,
stop/revocation, attempts, timing and standing SMS controls remain. A successful
Gmail acknowledgement completes sending and registers SMS independently of CRM
recording. Existing approved HTML packages preserve their exact original scope;
installation neither converts nor approves them.

Automatic name resolution, one CRM match and the scoped 24-hour project cache
remain. New runtime policy explicitly selects plain text over old saved preview
preferences. Shared rules/helpers, defaults and listing copy ship in both editions.

Offline validation covers plain MIME, a JSON-free user page with task-only
bindings, edited text/headers/window, localized submissions, injected checklist
text, consumed approvals, stops, no replay and provider handoff. Target-host
Notion formatting, original timed cycles and actual end-to-end latency still
require a live run. This release does not change real tasks or send messages.
